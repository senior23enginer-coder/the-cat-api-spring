# the-cat-api-spring

## Ficha del proyecto

Integración Java con The Cat API, con proyecto Maven y definición Docker.

### Contenido

- [src](./src), [pom.xml](./pom.xml), [Dockerfile](./Dockerfile).

### Uso

Revisa [pom.xml](./pom.xml) para consultar la versión de Java, las dependencias y los módulos Maven. Configura los servicios externos por separado.
